Six questions the interface can finally answer.

WGD turns reasoning into a small, composable interaction vocabulary instead of routing every uncertainty into a chat box.

WhyWhy did this appear, change, rank, or get recommended?
EvidenceWhat facts, sources, and gaps support this claim?
CompareWhat alternatives exist and what tradeoffs separate them?
ChallengeWhat is the strongest reasonable countercase?
ConfidenceWhat is known, inferred, uncertain, or calibrated?
ProvenanceWhere did this output come from and what transformed it?
Works with your AI

WGD is the interface layer, not the model.

The host supplies explicit context. WGD asks the right reasoning question. Your resolver, model, agent, or AI gateway returns the answer.

Five-minute install

One component. Your context. Your resolver.

Start locally with no backend, then point the same interface at your production AI endpoint.

npm install @wgd-ai/react@alpha import { Wgd } from "@wgd-ai/react"; import "@wgd-ai/core/style.css"; <Wgd intent="evidence" context={{ claim: "Lowest price in 60 days" }} config={{ endpoint: "/api/wgd" }} > Lowest price in 60 days </Wgd>
